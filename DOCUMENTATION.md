## 3. Routing and locale behavior

Page structure:

- `/` (custom redirect page)
- `/en/*`
- `/ro/*`
- `/ru/*`

Custom root behavior is implemented in `/Users/nicolaecretu24/Desktop/pouchwebsite_2/src/pages/index.astro`:

- With JS: detects `navigator.language`
- Supported browser locales: `en`, `ru`, `ro`
- Unsupported locale fallback: `/ro/`
- No-JS fallback: `/ro/`

## 4. SEO implementation

### 4.1 Base head tags

File: `/Users/nicolaecretu24/Desktop/pouchwebsite_2/src/layouts/BaseLayout.astro`

Per page, the layout renders:

- `title`
- `meta description`
- canonical URL
- `hreflang` alternates for `en`, `ro`, `ru`
- `x-default`
- Open Graph tags
- Twitter tags
- JSON-LD schema

Root page (`/`) behavior:

- non-indexable (`noindex,follow`)
- canonical points to `/ro/`
- JS locale redirect (supported: `en`, `ru`, `ro`; fallback: `ro`)

### 4.2 `x-default` behavior

`x-default` is now derived from the same page path (not hardcoded homepage):

- Preferred locale for `x-default`: `ro`
- Fallback if missing: first available alternate

So product/blog/legal pages all point `x-default` to their equivalent localized URL.

### 4.3 Sitemap and robots

- Sitemap is generated by `@astrojs/sitemap` during build.
- `robots.txt` points to `https://pauch.vip/sitemap-index.xml`.

Files:

- `/Users/nicolaecretu24/Desktop/pouchwebsite_2/public/robots.txt`
- generated output in `dist/` after `npm run build`

Directory: `/Users/nicolaecretu24/Desktop/pouchwebsite_2/src/content/products/`

## 6. Product UI behavior

- Catalog reads products from content collection.
- Catalog groups items into lines by `brand + strength`.
- Strength filter is the only active catalog filter.
- Product card strength labels map to `easy/medium/strong/hardcore`.
- Product images are expected from `public/images/products/`, currently mostly transparent `.png` for active cards.

Main files:

- `/Users/nicolaecretu24/Desktop/pouchwebsite_2/src/components/home/CatalogGrid.astro`

## 11. Current known constraints

- Product visibility is JSON-driven; files in image folders alone do not create products.
- `flavorCategory` is still required by schema even though UI filtering is strength-only.
- `site` is set to production domain (`https://pauch.vip`), so if a new domain is used, update `astro.config.mjs` and redeploy.
