# Pauch website — technical documentation

## Stack

- Astro 7 static output
- Astro Content Layer with JSON glob loaders
- Tailwind CSS 3 through PostCSS
- TypeScript 5
- Node 22.12+

Primary configuration lives in `astro.config.mjs`, `src/content.config.ts`, `src/config/site.ts`, and `src/config/commerce.ts`.

## Routing and localization

Localized routes use `/en/`, `/ro/`, and `/ru/`. Root `/` is an indexable, language-neutral selector and is the `x-default` URL. Equivalent localized pages publish reciprocal language alternates.

`src/layouts/BaseLayout.astro` owns canonical, alternate, Open Graph, Twitter, and shared identity metadata. Structured data is serialized by `src/lib/seo/jsonld.ts`; do not emit raw user-controlled JSON into script tags.

Astro generates `sitemap-index.xml`; the application also generates `image-sitemap.xml` and exposes `/build-info.json`. `public/robots.txt` advertises both sitemaps.

## Content collections

`src/content.config.ts` defines products, brands, blog posts, and hubs. Records live under `src/content/`.

Unknown commerce facts are explicit. In particular, product prices, maintained stock, Offer schema, and unverified manufacturer details must not be inferred. The current catalog groups products by brand and strength and uses localized content from the same record.

Blog markdown passes through the limited renderer in `src/lib/content/safeMarkdown.mjs`. It supports the required editorial subset while escaping unsafe HTML.

## Commerce and age controls

`src/config/commerce.ts` is the only source for ordering, delivery, payment, and Telegram settings. The age gate is visible by default, stores a versioned expiring decision, traps focus while open, and routes denials to local noindex pages.

## Images

Source assets keep their stable public paths. Responsive WebP derivatives and their manifest are generated by repository scripts and consumed through `src/lib/images/responsive.ts`. The inventory report is `docs/images/image-inventory.md`.

## Deployment

GitHub Pages hosts the custom production domain `pauch.vip` with enforced HTTPS. `.github/workflows/deploy.yml` runs the complete CI command for pull requests. Pushes to `main` run the same checks, upload `dist` as the Pages artifact, and deploy through the `github-pages` environment.
