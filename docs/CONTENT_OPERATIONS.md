# Content operations

Every new or changed localized page must be semantically equivalent in EN, RO, and RU and marked for native review. Numeric product facts require an official/packaging source URL and verification date. Price and stock additionally require an owner, currency, freshness rule, visible UI parity, and schema parity. Unknown availability stays `unknown`; Offer markup remains off.

Do not add fictional authors/reviewers, medical-review dates, reviews, ratings, affiliations, GTINs, operator details, social profiles, or image rights. Add real identities only after publishable approval. Health-adjacent copy needs source review and a responsible editor; cessation claims require particular care.

Use the corrections page and record material corrections. Existing public URLs and image URLs must remain stable unless a tested one-to-one redirect and migration map are shipped together.
